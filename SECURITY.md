# Security Policy

Security and data privacy are treated as first-class concerns throughout the project.

## Responsible Disclosure

Please do not disclose security vulnerabilities through public issues, pull requests, or discussions. Report suspected vulnerabilities privately to the maintainers, including clear reproduction steps, affected components, and potential impact where applicable.

## Sensitive Information

Never include the following in issues, pull requests, commits, or application logs:

* Credentials, API keys, or secrets
* JWTs or authentication tokens
* Customer personally identifiable information (PII)
* Other confidential or production-sensitive data

Following these practices helps protect users, maintainers, and the integrity of the platform.
